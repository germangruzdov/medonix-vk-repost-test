# МедОникс — тест репоста ВК

Версия 0.2.1 добавляет безопасную диагностику: при ошибке на экране видны этап операции и короткий код, отдельно различаются выдача права wall, чтение исходной записи и проверка прежнего репоста. Необработанные сообщения ВК, токены, параметры запросов и персональные данные в диагностику не включаются. Это диагностическое обновление; оно ещё не устанавливает причину ошибки в реальном ВК.

Статическая тестовая копия VK Mini App. Приложение ВК: **54874242**.

Скопировано без изменения логики из проверенной локальной версии 0.2.0. Основной режим отправляет настоящий репост записи `wall-218885671_6311` только после явного нажатия пользователя. Новый пост с видео находится отдельно на `video.html`.

Страница должна запускаться внутри зарегистрированного VK Mini App. В обычном браузере публикация отключена. ВК может отказать новому приложению в доступе `wall` или методе `wall.repost`; реальные права и мобильный результат ещё не подтверждены.

Пароли и секреты приложения не включены. Временный пользовательский токен выдаёт штатный диалог ВК; токен остаётся в памяти страницы, не логируется, не записывается в хранилище и не отправляется на сервер приложения.

Хостинг предназначен для технического теста. Перед распространением ссылки подписчикам нужно проверить реальную публикацию и воспроизведение на мобильной стене. Доступность из разных сетей и регионов может различаться.

`.nojekyll` отключает обработку файлов Jekyll. Корень ветки main используется как источник GitHub Pages.

Проверка логики: `node --test tests/*.test.mjs` (Node.js 22+). Тесты используют подмену VK Bridge, не выполняют реальные публикации.

SDK VK Bridge 3.0.2 включён в vendor без изменений. Его лицензия находится в `vendor/VK-BRIDGE-LICENSE.txt`.
